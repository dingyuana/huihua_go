## 二、待开发任务清单

### TASK-4.1 收款单"未核销金额"独立字段（P1 → P0 升级）

**目标**：把当前的 `outstanding_amount` 派生字段拆为独立的 `unallocated_amount`，与 ar_invoice 余额字段解耦。

**业务背景**：
- 16.2.1 字段定义中 `paid_amount` 是已核销金额
- 当前用 `outstanding_amount` 表达"未核销金额"—— 实际是应收回款余额（含未核销收款 + 未冲红）
- 16.2.4 V1.0 报告要求"未核销金额独立字段"为 P1 拆分

**实现步骤**：
1. migration: `ALTER TABLE payment_entries ADD COLUMN unallocated_amount NUMERIC(18,2) DEFAULT 0`
2. model: `PaymentEntry.UnallocatedAmount decimal.Decimal` 字段
3. service: 创建/过账时初始化；核销时扣减
4. handler: List/GetByID 返回字段
5. 前端：收款单详情显示"未核销金额"

**工作量**：0.5-1 天
**优先级**：P1（V1.0 报告中标记 P1，按用户"先 P1 再 P0"原则 —— 实际为最高优先级）

### TASK-4.2 收款单币种字段（P0）

**目标**：收款单支持多币种，扩展到采购端付款单（17.2）共用同一字段。

**业务背景**：
- 16.2.4 V1.0 报告标记币种为 P0 缺失
- 17.2.3 标记币种为 V2 远期（不实现）—— 故**仅销售端实现**

**实现步骤**：
1. migration: `ALTER TABLE payment_entries ADD COLUMN currency VARCHAR(3) DEFAULT 'CNY'` + `exchange_rate NUMERIC(18,6) DEFAULT 1.0`
2. model: `PaymentEntry.Currency` + `PaymentEntry.ExchangeRate` 字段
3. service: 创建时校验币种代码；汇率非 1.0 时记入 base_amount 字段
4. handler: 透传字段
5. 前端：表单币种下拉（CNY/USD/EUR/HKD 4 选 1）
6. 凭证生成：多币种时增加汇兑损益计算

**工作量**：1.5-2 天
**优先级**：P0
