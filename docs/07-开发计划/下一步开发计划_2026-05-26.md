### 1.2 已识别的缺失功能

根据财务人员专业评估，以下功能缺失影响项目完整性和合规性：

| 优先级 | 功能 | 影响 |
|---|---|---|
| P0 | 会计科目初始化 | 新公司无法快速建账 |
| P0 | 期初余额录入 | 新账套无法启用 |
| P0 | 现金流量指定 | 现金流量表数据可能不准确 |
| P0 | 凭证打印 | 无法装订会计档案 |
| P1 | 年度结转 | 无法跨年度账务处理 |
| P1 | 账簿打印 | 无法打印归档 |
| P1 | 固定资产批量导入 | 资产初始化效率低 |
| P1 | 工资批量导入 | 工资录入效率低 |
| P2 | 外币业务处理 | 有外币业务公司无法使用 |
| P2 | 数量金额式账簿 | 存货类科目无法数量管理 |
| P2 | 多栏账 | 费用类科目分析不便 |
| P2 | 往来对账单 | 客户/供应商对账不便 |
| P2 | 凭证模板 | 重复分录录入效率低 |

## 二、下一阶段开发计划（P0 优先级）

### 2.1 功能一：会计科目初始化

**目标：** 提供标准会计科目表导入功能，支持新公司快速建账。

**需求说明：**
- 内置标准会计科目表（企业会计准则 2006/2019 版本）
- 支持 Excel 导入自定义科目表
- 科目编码规则校验（1-6 级，4-2-2-2-2-2）
- 科目属性设置（余额方向、科目类型、辅助核算、外币核算、数量核算）
- 支持科目模板选择（工业企业、商业企业、服务业等）

**验收标准：**
- [ ] 内置标准科目表数据文件
- [ ] 提供科目表导入 API
- [ ] 前端提供科目模板选择界面
- [ ] 科目编码规则自动校验
- [ ] 科目属性批量设置

**预估工作量：** 3 天

**相关文件：**
- `backend/app/api/v1/subject_init.py`（新建）
- `backend/app/services/subject_init_service.py`（新建）
- `frontend/src/pages/setting/SubjectInit.vue`（新建）

### 2.2 功能二：期初余额录入

**目标：** 支持新账套启用时录入各科目的期初余额。

**需求说明：**
- 支持按科目录入期初余额（借方/贷方）
- 支持辅助核算科目的期初余额录入（按客户、供应商、部门等维度）
- 期初余额试算平衡校验（资产 = 负债 + 所有者权益）
- 期初余额锁定机制（一旦启用账套，期初余额不可修改）
- 支持期初余额 Excel 导入/导出

**验收标准：**
- [ ] 提供期初余额录入界面
- [ ] 试算平衡自动校验
- [ ] 辅助核算科目余额录入
- [ ] 期初余额锁定功能
- [ ] Excel 导入/导出功能

**预估工作量：** 5 天

**相关文件：**
- `backend/app/api/v1/opening_balance.py`（新建）
- `backend/app/models/opening_balance.py`（新建）
- `backend/app/services/opening_balance_service.py`（新建）
- `frontend/src/pages/setting/OpeningBalance.vue`（新建）

### 2.3 功能三：现金流量指定

**目标：** 为每笔涉及现金/银行存款的凭证指定现金流量项目，确保现金流量表数据准确。

**需求说明：**
- 内置现金流量项目（经营活动、投资活动、筹资活动）
- 凭证保存时自动提示指定现金流量（涉及 1001/1002 科目）
- 支持一笔凭证指定多个现金流量项目（金额拆分）
- 现金流量指定状态检查（期末结账前检查未指定凭证）
- 支持现金流量指定批量操作

**验收标准：**
- [ ] 内置现金流量项目数据
- [ ] 凭证保存时自动提示
- [ ] 现金流量指定界面
- [ ] 期末未指定凭证检查
- [ ] 现金流量表数据准确性验证

**预估工作量：** 5 天

**相关文件：**
- `backend/app/api/v1/cash_flow_specify.py`（新建）
- `backend/app/models/cash_flow_item.py`（新建）
- `backend/app/models/voucher_cash_flow.py`（新建）
- `frontend/src/components/CashFlowSpecifyDialog.vue`（新建）

### 2.4 功能四：凭证打印

**目标：** 提供标准会计凭证打印功能，支持装订归档。

## 五、智能回款核销模块（独立规划）

**需求文档：** `docs/02-需求分析/智能回款核销模块需求分析.md`

**模块定位：** 连接银行流水与销售发票，实现从"资金流入"到"账务核销"的自动化闭环。

**核心功能：**
1. 银行流水导入与初筛（出纳）
2. 销售协同认领（销售）
3. 智能匹配与人工核销（应收会计）
4. 核销审计与追溯（财务经理）

**技术实现：**
- 新建 `receivable_reconciliation` 表
- 扩展 `bank_transactions` 表（状态流转、业务分类）
- 扩展 `invoices` 表（已核销金额、未核销金额）
- 新建核销工作台前端页面

**预估工作量：** 10 天

**优先级：** P0（与上述 P0 功能并行开发）
