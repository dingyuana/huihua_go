**同时修改 `txn.is_reconciled` 的自动设置（行341附近）：**

现状：
```python
txn.status = "document_generated"
```

**注意：** `txn.status = "document_generated"` 保留，表示"已生成单据"，与"已对账"是两个独立概念。

### 3.2 P0.2：合并双重 db.commit()

**文件：** `backend/app/api/v1/cash.py`（import API，约行604附近）

**现状代码：**

```python
# 第一阶段：流水入库
db.add(transaction)
imported_txns.append(transaction)

# 批量提交
generated_docs = None
if imported_count > 0:
    db.commit()  # ← 第一次 commit（流水入库）

    # 自动生成收付款单
    gen_result = auto_generate_documents(db, imported_txns, current_user)
    if gen_result["generated"]:
        db.commit()  # ← 第二次 commit（收付款单），失败则流水已入库
```

**修改后：**

```python
# 所有操作在一个事务内
if imported_count > 0:
    # auto_generate_documents 内部使用 db.flush()，不自行 commit
    gen_result = auto_generate_documents(db, imported_txns, current_user)
    # 统一一次 commit（流水 + 收付款单同时成功或同时失败）
    db.commit()
```

**前提条件：** `auto_generate_documents` 函数内部必须只使用 `db.flush()`，不能有 `db.commit()`。

检查 `cash_service.py` 中的 `auto_generate_documents`：

```python
# 行351~358
if generated:
    db.flush()  # ← 已有 flush，无 commit，OK

return {
    "generated": generated,
    "already_exists": already_exists,
    "total": len(txns),
}
```

确认 `auto_generate_documents` 内部无 `db.commit()`，只需修改 import API。
