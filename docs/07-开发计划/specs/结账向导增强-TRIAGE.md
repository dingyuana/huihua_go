# TRIAGE：慧话财务 — 结账向导增强

## 需求摘要

参照单企业版月底结账SOP，对慧话财务的期末结账功能进行增强，扩展 `pre_close_check` 返回值，重构 PeriodClose 页面，将当前单一的"3项检查卡片"升级为带风险预警、关键指标环比、计提检查、人工确认清单的结构化结账向导。

## 识别到的约束

1. **单企业场景**：不引入多账套概念，所有改动在当前单账套架构上完成
2. **不改核心会计逻辑**：不修改凭证状态机、损益结转逻辑、结账锁定逻辑
3. **不改数据库结构**：零数据库迁移，纯查询逻辑
4. **后端只扩展现有接口**：只修改 `pre_close_check` 的返回值，不新增路由
5. **前端只改 PeriodClose.vue**：重用现有卡片布局，不重构路由或页面框架
6. **不引入外部依赖**：行业标准库等暂不做，环比只与上月对比
7. **OpenCode 执行**：所有代码变更通过 OpenCode 执行，Hermes 负责审核

## 假设

- 上月的 `acc_account` 数据存在（非新企业第一个月），若不存在则环比显示"无对比数据"
- 应收/应付科目的余额方向可通过 `acc_account.closing_balance` 的符号判断
- `fixed_assets` 表中如果有使用中资产，意味着需要计提折旧
- 税金计提通过 `tax_declarations` 表中的申报记录判断
