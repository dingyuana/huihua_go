# SPEC: TASK03 — 一键生成薪资凭证

## 基本信息

- **任务 ID**: phase2-wage-003
- **类型**: feature
- **优先级**: high
- **依赖**: phase2-wage-001（社保计提完成后在凭证中一并反映）
- **执行者**: OpenCode

## 背景

薪资数据已录入、社保已计提、个税已计算，但会计还需要手动从薪资数据做凭证。"生成薪资凭证"按钮是目前缺的最后一步。

## 目标

实现"一键生成薪资凭证"功能：一次调用生成3张凭证（工资计提、社保计提、个税计提）。

## 技术约束

- 调用 `create_voucher_core()`
- 凭证自动提交审核
- 更新 WageRegister.status = "posted"

## 详细设计

### API

```python
POST /wage/registers/{id}/generate-vouchers
```

生成3张凭证：

**凭证1：工资计提**
```
借：管理费用-工资（公司承担部分，按部门分摊简化版）
    销售费用-工资
    制造费用-工资（如有）
贷：应付职工薪酬-工资（应发合计）
```

**凭证2：社保公积金计提**
```
借：管理费用-社保/公积金（公司部分，由TASK01计算）
贷：应付职工薪酬-社保
贷：应付职工薪酬-公积金
```

**凭证3：个税计提**
```
借：应付职工薪酬-工资（个税部分，从应发中扣除）
贷：应交税费-应交个人所得税
```

**实发工资**：已在凭证1中反映为应付职工薪酬-工资的贷方，实际发放时：
```
借：应付职工薪酬-工资（实发部分）
贷：银行存款
```
（这步不自动生成，作为后续的付款单流程）

### 响应

```json
{
  "success": true,
  "vouchers": [
    {"type": "salary", "voucher_id": "...", "voucher_no": "记-..."},
    {"type": "social", "voucher_id": "...", "voucher_no": "记-..."},
    {"type": "tax", "voucher_id": "...", "voucher_no": "记-..."}
  ],
  "message": "已生成3张薪资相关凭证并提交审核"
}
```
