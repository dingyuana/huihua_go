## 基本信息

- **任务 ID**: phase2-wage-004
- **类型**: feature
- **优先级**: medium
- **依赖**: 无
- **执行者**: OpenCode

## 背景

薪资数据查看只能在页面上逐条看，无法导出为Excel发送给老板或HR。

## 目标

实现工资单Excel导出和个税明细导出。

## 技术约束

- 使用 `openpyxl` 生成Excel
- 导出路径在 `backend/app/services/wage_service.py` 中

## 详细设计

### API

```python
GET /wage/registers/{id}/export-salary   # 工资单导出
GET /wage/registers/{id}/export-tax       # 个税明细导出
```
