# Phase 3 TRIAGE — 税务申报表自动取数 & 台账预警

## 需求摘要

慧话财务已有税种配置(TaxType)、纳税申报状态管理(DeclarationList/Form)、税负率计算功能。但申报表数据需要会计手工填，系统不会自动从账面取数。核心价值缺失——"从账面数据自动生成申报表"没做。

## 识别到的约束

1. **不对接税局API**：申报表自动生成≠自动申报，只生成可导出/打印的申报表草稿，会计审核后自行提交给税局
2. **不重写税务模块**：现有 Declaration 状态机（draft→submitted→approved→filed）不变，只扩展"自动取数生成draft申报表"这一步
3. **取数来源**：从科目余额表取数（acc_account 表的 closing_balance）

## 假设

- 增值税申报表的栏次映射到科目编码是固定的（如"按适用税率计税销售额"=主营业务收入贷方发生额）
- 企业所得税预缴表的数据来源于利润表

## 依赖

- 无（可独立开发）
