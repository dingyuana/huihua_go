# SPEC: TASK01 — 增值税申报表自动取数

## 基本信息

- **任务 ID**: phase3-tax-001
- **类型**: feature
- **优先级**: high
- **依赖**: 无
- **执行者**: OpenCode

## 背景

会计需要在每个申报期从科目余额表手工取数填到增值税申报表。系统已记录科目余额，应自动填入。

## 目标

实现增值税申报表（主表）自动从科目余额取数生成草稿。

## 技术约束

- 数据来源：`acc_account` 表中该月的 `closing_balance`
- 生成的申报表数据写入 `TxDeclaration` 表（状态为 draft）
- 新增 `declaration_data` 字段（JSON格式）存储申报表各栏数据

## 详细设计

### 申报表栏次→科目映射

```
增值税申报表主表（一般纳税人简化版）：
----------------------------------------------------------------------
栏次 | 项目                        | 取数来源
1    | 按适用税率计税销售额        | 主营业务收入(6001) 贷方发生额
2    | 应税货物销售额              | 600101 贷方（如果有辅助核算）
3    | 应税劳务销售额              | 600102 贷方（如果有辅助核算）
4    | 纳税检查调整的销售额        | 0（不自动取数，手工填）
5    | 销项税额                    | 应交增值税-销项税额(222101) 贷方
6    | 进项税额                    | 应交增值税-进项税额(22210101) 借方
7    | 上期留抵税额                | 上期申报表的留抵结余
8    | 进项税额转出                | 应交增值税-进项税额转出(222102) 贷方
9    | 实际抵扣税额                | min(进项-转出, 销项)
10   | 应纳税额                    | 销项 - 实际抵扣
```

### API

```python
POST /tax/declarations/generate-vat
参数: { year, month }
返回: { declaration_id, status: "draft", data: {...}, message: "增值税申报表已生成" }
```

### 跨期数据

- 上期留抵税额：从最近一个已申报的期间取
- 本月无数据时标记"零申报"

## 验收标准

- [ ] 选择月份 → 生成增值税申报表 → 各栏次数据自动填入
- [ ] 结果保存为 TxDeclaration（状态=draft）
- [ ] 手工可修改自动填入的数据
- [ ] 零申报自动检测
