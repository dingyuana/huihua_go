# SPEC: TASK03 — 申报台账与逾期预警

## 基本信息

- **任务 ID**: phase3-tax-003
- **类型**: feature
- **优先级**: medium
- **依赖**: 无
- **执行者**: OpenCode

## 背景

税务申报按税种、按月度/季度有不同的截止日期。会计需要一张台账清晰看到每个税种的申报状态，以及哪些即将逾期。

## 目标

创建按税种+期间维度的申报状态矩阵，自动检测逾期风险。

## 详细设计

### 申报台账

```
┌────────────────────────────────────────────────────────┐
│  税种       | 1月 | 2月 | 3月 | ... | 状态           │
│  ────────── |──── |──── |──── |──── |──────────────── │
│  增值税      | ✅  | ✅  | ✅  |     | 全部已报       │
│  附加税      | ✅  | ✅  | ✅  |     | 全部已报       │
│  企业所得税  | ✅  | ✅  |     |     | 3月未报(⚠️)    │
│  印花税      |     |     |     |     | 0申报(无需报)  │
└────────────────────────────────────────────────────────┘
```

### 逾期检测规则

```
增值税：每月15日
附加税：每月15日（与增值税同步）
企业所得税：每季度结束后15日
印花税：每季度结束后15日
```

检测逻辑：当前日期 > 截止日期 + 该期还未申报 → 标红预警

### API

```python
GET /tax/table  # 返回申报状态矩阵
GET /tax/alerts # 返回逾期预警列表
```

## 验收标准

- [ ] 已报状态有标记
- [ ] 逾期自动标红预警
