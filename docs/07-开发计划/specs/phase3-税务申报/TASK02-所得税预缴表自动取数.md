## 背景

季度申报企业所得税时，需要从利润表取数填入预缴申报表（A类）。

## 目标

实现企业所得税预缴申报表（A类）从利润表数据自动取数。

## 详细设计

### 预缴申报表栏次→取数来源

```
栏次 | 项目              | 取数来源
1    | 营业收入          | 利润表：营业收入（主营业务收入+其他业务收入）
2    | 营业成本          | 利润表：营业成本（主营业务成本+其他业务成本）
3    | 利润总额          | 利润表：利润总额
4    | 减：减免所得税额  | 小微企业自动计算（利润≤100万: 实际税率5%）
5    | 减：实际已预缴    | 本年度累计已预缴税额
6    | 应补（退）所得税额| 计算
```

### 减免费用的计算逻辑

小微企业优惠政策：
```
年应纳税所得额 ≤ 100万: 实际税率5%（减免20%）
100万 < 年应纳税所得额 ≤ 300万: 分段计算
年应纳税所得额 > 300万: 实际税率25%
```

### API

```python
POST /tax/declarations/generate-cit
参数: { year, month, quarter }
```
