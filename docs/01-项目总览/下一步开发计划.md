# Phase 1：高频业务单据 & 自动凭证映射（P0 缺口）

## 说明

会计日常使用的三类高频业务单据（费用报销单、收款单、付款单），填单后一键生成凭证。

**现状**：无独立费用报销入口，只能通过手工凭证录入

**要做的**：
- 新建费用报销单页面（日期、摘要、金额、费用类型、部门、附件上传）
- 费用报销单列表（按日期/状态筛选）
- **一键生成凭证**：根据费用类型自动匹配科目，生成借：费用科目 贷：银行存款/其他应付款

**验收**：会计填一张报销单 → 点击生成凭证 → 看到自动生成的借贷分录 → 审核过账

### 1.2 收款单 / 付款单

**现状**：收款付款走手工凭证，关联不到客户/供应商

**要做的**：
- 收款单页面（客户选择、金额、收款方式、银行账户、摘要）
- 付款单页面（供应商选择、金额、付款方式、银行账户、摘要）
- 自动关联应收/应付往来明细
- **一键生成凭证**：收款生成借：银行存款 贷：应收账款；付款反之

**验收**：选择客户 → 填写收款金额 → 自动更新应收账款余额 → 生成对应凭证

### 1.3 单据→凭证自动映射规则

**现状**：每种单据的凭证模板写在代码里，改一个分录就要改代码

**要做的**：
- 维护一个配置表：单据类型 → 默认借贷科目
- 允许管理员自定义映射（如"差旅费报销单默认贷方科目从'银行存款'改为'现金'"）
- 前端提供一个简易配置页面

**验收**：管理员可以在页面上修改自动生成凭证的科目映射，改完后新单据按新规则生成

**估工**：2-3周（1.1+1.2+1.3）

## Phase 2：薪资->凭证闭环（P1 补最后一公里）

### 2.1 社保公积金计提

**现状**：有员工花名册、薪资台账，但社保公积金数据不在系统中

**要做的**：
- 社保基数配置表（每个员工的养老/医疗/失业/工伤/生育/公积金基数和比例）
- 月度社保计提计算（按配置自动生成应缴金额）
- 生成计提凭证（借：管理费用-社保 贷：应付职工薪酬-社保）

**验收**：选择月份 → 点击计提 → 系统计算所有员工社保 → 生成计提凭证

### 2.2 个税自动计算

**现状**：无个税计算逻辑

**要做的**：
- 内置累计预扣法计算逻辑（每月应纳税所得额 = 累计收入 - 累计免税收入 - 累计减除费用 - 累计专项扣除 - 累计专项附加扣除）
- 从薪资台账取数自动算个税
- 生成个税计提凭证

**验收**：输入某员工月薪 → 系统按累计预扣法算出当月个税 → 生成凭证

### 2.3 薪资一键生成凭证

**现状**：薪资数据录入了，但生成凭证要手工做

**要做的**：
- "生成薪资凭证"按钮：自动生成借：管理费用/销售费用-工资 贷：应付职工薪酬
- 社保/个税凭证同步生成

**验收**：月度薪资录入完成后 → 点击一键 → 3张凭证（工资/社保/个税）自动生成并提交审核

### 2.4 薪资报表 + 个税明细导出

**现状**：有列表查看但无结构化导出

**要做的**：
- 工资单导出Excel
- 个税申报明细导出（格式兼容个税系统）

**估工**：1.5-2周

## Phase 3：税务申报自动取数（P1 价值提升）

### 3.1 增值税申报表自动生成

**现状**：有申报状态管理，但申报表数据要会计手工填

**要做的**：
- 从科目余额自动提取：销项税额（222101）、进项税额（22210101）、转出未交增值税（222103）等
- 自动填入申报表主表对应栏次
- 支持人工调整（税会差异栏）
- 生成申报表草稿，会计审核后提交

**验收**：选择期间 → 点击生成申报表 → 系统从账套取数填表 → 会计审核调整 → 提交

### 3.2 企业所得税预缴表自动生成

**要做的**：
- 从利润表取营业收入、营业成本、利润总额
- 按小微企业税率优惠自动计算
- 支持纳税调增/调减手工录入

### 3.3 申报台账 + 逾期预警

**现状**：有申报状态标记但无日历维度的台账

**要做的**：
- 按税种 + 期间维度展示申报状态矩阵
- 距截止日期<7天未申报 → 自动提示
- 零申报自动检测（应纳税额=0时自动标记零申报）

**估工**：2-3周

## 建议执行策略

1. **Phase 1 先做**——这是因为会计每天都要填单据，**缺了这个慧话就缺了最基础的业务入口**
2. **Phase 5 穿插**——这些0.5-1天的小优化可以插在Phase之间做
3. **Phase 3 和 Phase 4 可以并行**——税务和档案是两个独立模块，不冲突
4. **Phase 2 依赖Phase 1的部分成果**——薪资凭证里如果有社保计提，计提凭证的模板映射逻辑可以和Phase 1.3共用
