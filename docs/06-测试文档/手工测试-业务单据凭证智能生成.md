## 附录 A：DB 直查脚本

```sql
-- A.1 检查 bus_doc_mapping 配置
SELECT doc_type, condition_key, debit_subject_code, credit_subject_code, is_active
FROM bus_doc_mapping ORDER BY doc_type, sort_order;

-- A.2 检查最新生成的凭证
SELECT voucher_no, source_doc_type, source_doc_no, counterparty_name, remark, docstatus
FROM journal_entries ORDER BY created_at DESC LIMIT 5;

-- A.3 检查凭证分录
SELECT je.voucher_no, a.code, a.name, jel.debit, jel.credit, jel.user_remark
FROM journal_entry_lines jel
JOIN journal_entries je ON je.id = jel.journal_entry_id
JOIN accounts a ON a.id = jel.account_id
WHERE je.voucher_no = 'PZ-XXXXX';

-- A.4 检查单据回滚
SELECT payment_no, docstatus, voucher_id, voucher_no, description
FROM payment_entries WHERE docstatus IN (0, 1) ORDER BY created_at DESC LIMIT 5;

-- A.5 检查 counterparty_name 一致性
SELECT je.voucher_no, je.counterparty_name as v_cp, pe.payment_no, pe.counterparty_name as pe_cp
FROM journal_entries je
JOIN payment_entries pe ON pe.id = je.source_doc_id
WHERE je.source_doc_type = 'payment_entry'
  AND je.counterparty_name IS DISTINCT FROM pe.counterparty_name
LIMIT 10;
```
