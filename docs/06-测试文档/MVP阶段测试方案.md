# AI智能财务助手 — MVP阶段测试方案

**文档版本：** V1.0  
**对应产品版本：** MVP V5.1（纯Web端）  
**测试周期：** MVP开发完成后，预计2-3周  
**测试目标：** 验证传统Web端六大模块功能完整性、业务逻辑正确性、数据安全性与系统稳定性


## 一、测试目标与范围

### 1.1 测试目标

| 目标 | 说明 | 成功标准 |
|:---|:---|:---|
| **功能完整性** | 验证MVP阶段定义的六大模块全部功能可正常使用 | 所有P0用例通过率100% |
| **业务逻辑正确性** | 验证借贷平衡、试算平衡、期末结转等核心财务逻辑无误 | 账务数据校验零误差 |
| **数据安全性** | 验证传输加密、存储加密、操作日志等安全措施生效 | 安全测试用例全部通过 |
| **系统稳定性** | 验证系统在预期负载下稳定运行 | 7×24小时无崩溃 |

### 1.2 测试范围（MVP明确包含与排除）

| 模块 | 测试范围（包含） | 排除范围（不测） |
|:---|:---|:---|
| **数据采集** | 发票文件上传+手工录入、银行流水Excel/CSV导入+手工录入、发票号查重 | 拍照OCR、微信卡片、语音记账、银行API直连 |
| **智能处理** | 手工科目选择、凭证草稿编辑、审核工作台（分屏）、批量审核、冲红账、反审核；制单人与审核人可为同一人 | AI科目推荐、置信度分级、角色强制分离 |
| **期末处理** | 损益结转、试算平衡检查、结账、反结账 | 计提折旧、汇兑损益、工资分摊 |
| **税务合规** | 发票号查重、税负率展示 | 对接税局验真、批量申报、个税处理 |
| **结果输出** | 资产负债表、利润表、科目余额表、总账/明细账、PDF/Excel导出 | 现金流量表、多栏账、辅助核算汇总表 |
| **决策支持** | 仅报表查看 | 经营驾驶舱、自然语言问答、预警推送 |

|:---|:---|:---|

|:---|:---|:---|
| 测试管理 | Excel / 禅道 / TestLink | 用例管理、缺陷跟踪 |
| 接口测试 | Postman | API接口手工验证 |
| 性能测试 | JMeter | 并发负载测试 |
| 安全扫描 | OWASP ZAP | Web安全漏洞扫描 |
| 浏览器调试 | Chrome DevTools | 网络请求检查、性能分析 |

### 7.2 测试数据初始化脚本

需开发以下脚本，用于测试环境快速重置：

- **科目表初始化脚本**：导入标准《小企业会计准则》科目
- **测试数据生成脚本**：批量生成发票、银行流水、凭证数据
- **账套重置脚本**：清除测试数据，恢复初始状态（用于回归测试）
