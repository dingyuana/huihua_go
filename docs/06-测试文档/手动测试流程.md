## 十二、验收标准

- [ ] 所有 P0 用例（带 `*` 标记）通过率 100%
- [ ] 核心业务链路可走通（制单→审核→过账→结账→出报表）
- [ ] 角色权限校验准确，无越权访问
- [ ] 所有表单校验正常工作，无 SQL 注入等明显安全漏洞
- [ ] 页面响应正常，无明显样式错乱
