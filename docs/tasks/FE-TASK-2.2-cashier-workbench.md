### 具体步骤

1. **API 对接**
   - `GET /bank-transactions` — 列表（支持 `classification`, `direction`, `matched`, 分页）
   - `PUT /bank-transactions/:id/classify` — 单条修正分类
   - `POST /bank-transactions/batch-classify` — 批量修正
   - `POST /bank-transactions/:id/confirm` — 单条确认
   - `POST /bank-transactions/batch-confirm` — 批量确认

2. **Store**（`src/stores/modules/bank.store.ts`）
   - `pendingCount`, `confirmedCount`, `unclassifiedCount` — 统计卡片
   - `currentList` — 当前列表数据
   - `fetchList(params)` — 按条件加载

3. **顶部统计卡片**
   - 本月待处理总数 | 已确认 | 待处理
   - 点击各卡片可快速筛选

4. **分类 Tab 栏**
   - `[全部] [业务收款] [业务付款] [银行费用] [利息收入] [内部转账] [待处理🔴]`
   - Tab 切换到 `classification=pending` 时红色高亮
   - 每个 Tab 显示该分类的数量角标

5. **列表操作**
   - 多选复选框 + 全选
   - 每行展示：日期、摘要、金额（绿色正/红色负）、分类标签、状态
   - 待处理行红色高亮闪烁指示

6. **批量操作（底部工具栏）**
   - 「确认选中」— 批量 `batch-confirm`
   - 「修正分类」— 弹窗批量修改分类
   - 「标记待处理」— 批量取消分类

7. **修正分类弹窗**
   - 下拉选择新分类
   - 对方单位选择器（`PartySelector`）
   - 备注输入
