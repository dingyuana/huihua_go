### 具体步骤

1. **API 对接**
   - `POST /bank-reconciliation/run` — 执行匹配
   - `GET /bank-reconciliation/matches` — 查看匹配结果
   - `POST /bank-reconciliation/confirm` — 确认匹配
   - `GET /bank-reconciliation/balance-sheet` — 余额调节表
   - `POST /bank-reconciliation/lock` — 锁定
   - `POST /bank-reconciliation/unlock` — 解锁

2. **对账匹配看板**
   - 顶部统计：自动勾兑率(百分比) | 未匹配数 | 待确认数
   - 进度条可视化勾兑率，颜色：>90%绿，>80%黄，<80%红
   - Tab 按匹配状态分组：「全部」「自动匹配」「待确认」「未匹配」
   - 列表行：匹配得分（进度条）+ 银行流水信息 + GL 信息 + 操作
   - 得分色标：≥85 绿色 ✓、60-85 黄色 ⚠️、<60 红色 ❌

3. **执行对账流程**
   - 选择账户+期间 → 点击「执行对账」→ 展示进度条
   - 完成后自动刷新匹配结果列表

4. **余额调节表页**
   - 顶部：银行余额 vs 企业余额 → 差额
   - 四类差异卡片：
     - 银行已收企业未达
     - 银行已付企业未达
     - 企业已收银行未达
     - 企业已付银行未达
   - 每张卡片列表明细：日期 + 金额 + 描述
   - 底部：调整后余额 + 平衡状态

5. **锁定/解锁**
   - 对账确认后「锁定」按钮可用
   - 锁定后所有匹配操作禁用，显示锁定状态
   - 解锁需输入原因（主管权限）
