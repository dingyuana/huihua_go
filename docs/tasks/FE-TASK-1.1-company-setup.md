## 任务描述

实现账套创建向导页面，用户分步完成公司信息、会计期间、初始化设置。

### 页面路径

`/setup/company` → `SetupWizard.vue`

### 页面原型

```
Step 1/3: 公司信息
┌─────────────────────────────────────┐
│ 公司名称     [__________________]   │
│ 启用日期     [2026-01-01    ▼]      │
│ 本位币       [CNY ▼]                │
│                                   │
│              [下一步]               │
└─────────────────────────────────────┘

Step 2/3: 会计期间
┌─────────────────────────────────────┐
│ 财务年度起始月  [一月 ▼]            │
│ 期间类型      [◎ 自然月度  ○ 自定义]│
│ 期间数        [12]                  │
│ 预览          ┌─────────────────┐   │
│               │ 2026-01  ~ 2026-12│  │
│               └─────────────────┘   │
│              [上一步] [下一步]       │
└─────────────────────────────────────┘

Step 3/3: 初始化
┌─────────────────────────────────────┐
│ ☑ 导入内置科目表（小企业会计准则）   │
│ ☐ 创建默认资金账户                   │
│ ☐ 导入示例客商数据                   │
│                                   │
│              [上一步] [完成创建]     │
└─────────────────────────────────────┘
```

### 具体步骤

1. **API 对接**
   - `POST /api/v1/companies` — 创建账套
   - `POST /api/v1/periods/generate` — 生成期间
   - `GET /api/v1/periods?year=2026` — 查询已生成的期间

2. **Store 定义**
   - 无需独立 Store，使用 `tenant.store.ts` 缓存当前公司信息

3. **组件结构**
   - `SetupWizard.vue` — 主容器，`el-steps` 步骤条 + 3 个 Step 面板
   - 每个 Step 内嵌表单，最后一步汇总展示配置项

4. **校验逻辑**
   - 公司名称必填，长度 ≤ 100
   - 启用日期在 2026-01-01 ~ 当日范围
   - 期间数 1-12 整数

5. **创建完成后**
   - 跳转到 Dashboard，显示「账套创建成功」通知
   - 侧边栏菜单自动刷新
