### 具体步骤

1. **API 对接**
   - `GET /vouchers` — 列表（支持类型/状态/日期/分页）
   - `GET /vouchers/:id` — 详情（含分录行）
   - `POST /vouchers` — 创建草稿
   - `POST /vouchers/:id/submit` — 提交审核
   - `POST /vouchers/:id/cancel` — 作废
   - `POST /vouchers/:id/reverse` — 红字冲销
   - `GET /vouchers/next-no` — 预览编号

2. **列表页**
   - 筛选栏：类型下拉、状态下拉、日期范围、关键词
   - 表格：凭证号 | 日期 | 摘要 | 借方合计 | 贷方合计 | 状态（DocStatusTag）
   - 状态着色：草稿灰色，已审核蓝色，已作废红色删除线
   - 行点击跳转详情/编辑

3. **编辑页**
   - 顶部：摘要（输入）、日期（日期选择）、类型（下拉）、凭证号（自动生成，只读）
   - 分录行表格
   - 每行：科目选择器（`AccountSelector`，过滤 `is_group=false`）+ 借方金额 + 贷方金额 + 辅助核算 + 删除按钮
   - 每行互斥：借方有值则贷方置灰，反之亦然
   - 底部：借方合计/贷方合计（实时计算）+ 平衡状态（✅/❌）
   - 「添加行」按钮追加空行
   - 保存草稿 = 调用 POST（docstatus=0）
   - 提交审核 = 调用 POST /submit（借贷平衡校验在后端）

4. **红字冲销弹窗**
   - 选择冲销日期
   - 填写冲销原因（必填）
   - 确认后自动生成反向分录预览

5. **辅助核算弹窗**
   - 点击辅助核算列弹出选择：客商、成本中心、项目

## 验收标准

- [ ] 列表页按类型/状态/日期筛选，分页正常
- [ ] 新增凭证时借贷方合计实时计算，不等时显示 ❌ 红色
- [ ] 借方有值时贷方自动置灰，反之亦然（每行互斥）
- [ ] 提交审核时借贷不平衡阻止提交（前端+后端双重校验）
- [ ] 已审核凭证只读，按钮置灰
- [ ] 红字冲销生成反向分录预览
- [ ] 草稿自动保存到 localStorage（防浏览器崩溃丢失数据）
