## 任务描述

实现科目表的树形展示、CRUD 操作、编码自动生成。

### 页面路径

`/setup/accounts` → `AccountChart.vue`

### 具体步骤

1. **API 对接**（使用 FE-TASK-0.2 的 `account.ts`）
   - `GET /accounts/tree` — 加载完整科目树
   - `POST /accounts` — 创建科目
   - `PUT /accounts/:id` — 更新科目
   - `DELETE /accounts/:id` — 删除科目
   - `GET /accounts/auto-code` — 预览编码

2. **Store**（`src/stores/modules/account.store.ts`）
   - `tree: Account[]` — 完整科目树
   - `ledgerOnly: Account[]` — computed，`is_group=false` 的可记账科目
   - `fetchTree()` — 从 API 加载
   - `getPath(code)` — 返回完整路径如「资产 > 流动资产 > 银行存款」

3. **组件结构**
   - 左侧：使用 `el-table` 展示树形数据（`tree` 属性 + `indent` 缩进）
   - Group 行使用黄色背景标记，Ledger 行白色
   - 右侧弹窗：新建/编辑科目表单

4. **增删改弹窗**
   - 新建：选择父科目 → 自动生成编码预览 → 填写名称/类型/币种
   - 编辑：修改名称/类型（编码不可修改）
   - 删除：二次确认，提示「已存在 X 条业务引用，不可删除」或「确认删除」
   - Group 科目不可改为 Ledger（如有子科目）

5. **编码自动生成**
   - 前端调用 `POST /accounts/auto-code` 预览编码
   - 展示建议编码并允许用户确认

6. **搜索过滤**
   - 输入关键词实时过滤树节点（名称 + 编码）
   - 支持按 `account_type` 下拉筛选
   - 支持切换「仅显示可记账科目」
