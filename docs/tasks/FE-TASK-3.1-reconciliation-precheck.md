### 具体步骤

1. **API 对接**
   - `POST /reconciliation/precheck` — 执行预检
   - `POST /reconciliation/match` — 执行匹配
   - `POST /reconciliation/match/confirm` — 确认推荐

2. **核销预检页**
   - 左侧选择收款单/付款单（支持模糊搜索）
   - 右侧选择待核销发票（显示未结清金额）
   - 「执行预检」按钮
   - 6 项检查结果清单展示（通过 ✅ / 警告 ⚠️ / 阻断 ❌）
   - 阻断项红色底色 + 展开详情
   - 「强制通过」按钮（需填写原因备注）

3. **匹配推荐页**
   - 顶部展示收付款单信息卡片
   - 按匹配层级分组展示推荐结果
   - L1/L2 自动勾选 + 绿色底色（无需确认）
   - L3 模糊匹配黄色底色 + 「确认」「忽略」按钮
   - 每组显示匹配得分进度条
   - 底部「确认全部匹配」批量操作

4. **状态管理**
   - 选中的收付款与发票在 Store 中暂存
   - 预检结果缓存，刷新后保留
