### 7.1.2 现金流预测

基于历史收付款规律 + 应收应付账期，预测未来 3-6 个月现金流：

```go
type CashFlowForecast struct {
    Horizon    int         // 预测月数
    Monthly    []MonthCash  // 每月预测
    Alerts     []Alert      // 预警（资金缺口/大额支出）
}

type MonthCash struct {
    Month       string
    Opening     decimal.Decimal
    Receivable  decimal.Decimal  // 预计收款
    Payable     decimal.Decimal  // 预计付款
    Balance     decimal.Decimal  // 期末
}
```

预测模型：
- 历史同期法：近 3 年同月平均值
- 账期推算法：应收账款账期 × 平均月收款估算
- 趋势外推：线性回归短期趋势

### 7.1.3 经营月报自动生成与推送

每月结账后，AI 自动生成图文并茂的经营分析长图，通过 IM 推送：

```

- 异常提醒（成本超支/逾期应收账款）
```

长图生成：使用 charts 库生成图表，渲染为 PNG，通过 IM 接口推送。

## 上下文信息（架构师决策记录）

- **决策**：AI 解读采用 RAG 增强而非纯 LLM 记忆，因为财务数据是实时变化的，必须结合当前账套数据
- **风险**：现金流预测精度受历史数据质量影响，历史数据不足 12 个月时，预测结果仅供参考
- **风险**：LLM 幻觉（事实错误）风险在财务场景下不可接受，必须在 Prompt 中要求"仅基于提供的数据回答，不知道时说不知道"
