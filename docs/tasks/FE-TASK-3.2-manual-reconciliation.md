## 任务描述

实现手工核销操作：选发票、分配金额、执行核销、回退。

### 页面路径

`/reconciliation/manual` → `ManualMatch.vue`

### 具体步骤

1. **API 对接**
   - `GET /reconciliation/candidates` — 获取可选发票列表
   - `POST /reconciliation/manual-allocate` — 手工分配
   - `POST /reconciliation/:id/reverse` — 核销回退
   - `GET /reconciliation/allocations` — 历史核销记录

2. **左右分栏布局**
   - 左侧：收款单/付款单详情卡片（已选中的单据）
   - 右侧：可选发票列表（未结清金额 > 0）
   - 勾选发票后自动添加到下方已分配列表

3. **已分配核销表**
   - 行：发票号 + 未结清金额（只读）+ 本次核销金额（可编辑） + 核销后余额（自动计算）
   - `AmountInput` 组件限制最大值 = 未结清金额
   - 底部合计行：本次核销合计 ≤ 收款单未分配金额

4. **核销回退弹窗**
   - 选择要回退的核销记录
   - 填写回退原因（必填）
   - 确认后自动更新发票余额

5. **校验**
   - 核销金额合计 > 收款单未分配金额时，按钮禁用 + 提示「已超可分配金额」
   - 未勾选任何发票时按钮禁用
   - 核销金额 = 0 的行提交前校验拒绝
