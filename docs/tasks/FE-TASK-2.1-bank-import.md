### 具体步骤

1. **API 对接**
   - `POST /bank-transactions/import` — 上传文件 + 解析
   - `GET /field-mapping-templates` — 获取预设映射模板
   - `POST /field-mapping-templates` — 保存自定义映射

2. **文件上传区**
   - 使用 `el-upload` 拖拽上传
   - 限制格式：`.xlsx`, `.xls`, `.csv`, `.xml`
   - 上传后显示文件名 + 格式识别结果 + 文件大小
   - 大文件（>10MB）提示「文件较大，解析可能需要较长时间」

3. **字段映射面板**
   - 自动匹配的字段显示绿色 ✓
   - 未匹配的字段显示黄色 ⚠️ 下拉选择
   - 下拉选项从文件表头动态读取
   - 支持保存模板供下次复用

4. **预览表格**
   - 展示解析后的前 5-10 条数据
   - 高亮必填字段缺失的行
   - 点击行可查看原始数据

5. **导入结果**
   - 导入完成后展示结果卡片：总数 / 成功 / 重复 / 失败
   - 失败原因列表（每行一条）
   - 「查看导入详情」按钮跳转到核对工作台
