## 任务描述

实现客户/供应商档案的列表、CRUD、Excel 批量导入。

### 页面路径

`/setup/parties` → `PartyList.vue`

### 具体步骤

1. **API 对接**
   - `GET /parties` — 列表（支持 `keyword`, `party_type`, `page`, `pageSize`）
   - `POST /parties` — 新建
   - `PUT /parties/:id` — 更新
   - `DELETE /parties/:id` — 删除
   - `POST /parties/import` — Excel 导入
   - `GET /parties/search` — 快速搜索（供选择器使用）

2. **表格**
   - 使用 `el-table`，列：名称 | 税号 | 类型（标签） | 开户行 | 账号 | 信用额度 | 账期 | 联系人 | 操作
   - 顶部 Tab 切换：「全部」「客户」「供应商」
   - 支持按类型、状态筛选

3. **新建/编辑弹窗**
   - 基础信息卡片：名称、税号（18 位统一社会信用代码校验）、类型、电话、地址
   - 财务信息卡片：开户行、账号、信用额度、账期策略（net15/net30/net60/自定义）
   - 联系人卡片（可选）：姓名、电话、邮箱

4. **Excel 导入**
   - 上传区域（拖拽 + 点击），仅支持 `.xlsx` / `.xls`
   - 上传后实时展示导入结果（总数/成功/失败/错误行号）
   - 错误行可点击下载错误报告

5. **客商选择器联动**
   - 在 `PartySelector.vue` 组件中注册搜索 API
   - 确保其他模块（发票、核销）的客商选择器正确工作
