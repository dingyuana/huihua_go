## TASK-3.4：现金折扣模型 + service

**优先级**: 🔴 P0
**工作量**: 1-2 天
**依赖**: TASK-3.1（核销端点）
**目标文件**（新增）:
- `/root/data/disk/huihua-finance/internal/model/cash_discount.go`
- `/root/data/disk/huihua-finance/internal/repository/cash_discount_repo.go`
- `/root/data/disk/huihua-finance/internal/service/cash_discount_service.go`
- `/root/data/disk/huihua-finance/internal/handler/cash_discount_handler.go`

### 业务背景

**V1.0 §3.7 新增场景**（采购端独有）：
- 供应商为鼓励提前付款提供折扣（如 2/10 N/30）
- 付款金额可能小于应付余额，差额作为折扣
- 凭证：
  ```
  借：应付账款（全额）
    　　贷：银行存款（实付）
    　　贷：财务费用—利息收入（折扣）
  ```

### 数据模型

```go
type CashDiscount struct {
    ID             uuid.UUID
    PaymentEntryID uuid.UUID       // 关联付款单
    ApInvoiceID    uuid.UUID       // 关联应付单
    DiscountAmount decimal.Decimal // 折扣金额
    DiscountRate   decimal.Decimal // 折扣率（如 0.02 = 2%）
    CreatedAt      time.Time
    CreatedBy      uuid.UUID
}
```

### payment_allocations 表加字段

```sql
ALTER TABLE payment_allocations ADD COLUMN discount_amount DECIMAL(18,2) DEFAULT 0;
```

### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/cash-discounts` | 折扣记录列表 |
| GET | `/api/v1/cash-discounts/:id` | 详情 |
| GET | `/api/v1/cash-discounts/by-payment/:payment_entry_id` | 按付款单查 |

### 核销流程改造

`payment-entries/:id/allocate` 接受可选参数 `discount_amount`：
- discount_amount = 0：原流程（无折扣）
- discount_amount > 0：
  - 写入 cash_discounts 表
  - payment_allocations.discount_amount 字段记录
  - 自动生成凭证（含财务费用科目 6603）

### 验收

- 折扣模型 + repo + service + handler 完整
- 1 个端到端测试：付款 100 元冲应付 102 元 + 折扣 2 元 → 凭证正确
