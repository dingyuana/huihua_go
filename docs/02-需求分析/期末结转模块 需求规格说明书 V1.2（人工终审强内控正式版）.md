## 0\. 核心刚性约束（最高优先级，不可绕过、不可配置、不可例外）

本约束为模块设计底层红线，优先级高于所有业务流程、功能配置、特殊场景，系统无任何开关可关闭。

**2\. 草稿凭证不计入正式账务、不更新科目余额、不参与报表取数、不允许期末结账。**

**3\. 系统禁止一切自动过账、自动审核、自动确认结转行为，无定时触发、无后台静默执行机制。**

## 1\. 模块定位

期末结转是慧话财务整体账务链路「业务单据→日常凭证→审核记账→期末结转→财务分析→期末关账」的核心闭环环节。

模块核心运行模式：**人工主动发起、系统规则计算、生成非正式草稿、人工逐笔终审、人工确认过账入账**。

模块不替代人工会计判断，仅标准化、自动化期末结转的计算与分录组装工作，所有账务结果最终由人工兜底负责，满足企业内控、审计、税务合规要求。

## 2\. 整体设计原则（强制执行）

|原则|详细说明|
|---|---|
|人工发起|所有结转操作必须财务人员手动进入页面、手动点击执行，系统无自动触发、无月末定时任务、无后台自动结转逻辑。|
|模板驱动、无自主判断|所有结转分录、取数规则、科目映射、分摊比例均由模板定义，系统仅按模板执行计算，不自主新增、删减、修改分录规则。|
|草稿隔离、账证分离|草稿阶段完全隔离正式账务数据，不影响余额、报表、结账状态，彻底规避自动入账带来的账务风险。|
|人工终审、两步分离|生成草稿、审核草稿、确认过账为独立三步，审核通过不自动过账，必须人工二次确认，杜绝流程自动跳转。|
|原子事务、数据一致|单类结转草稿生成整体事务回滚；过账操作整体事务执行，要么全部成功入账，要么全部回滚，杜绝部分入账、数据错乱。|
|权限互斥、内控闭环|制单、审核、过账、模板配置权限严格隔离互斥，一人不可全程包办，全流程操作可追溯、不可篡改。|
|可配置可扩展|兼顾通用标准场景与行业特殊场景，支持集团统一管控\+单体灵活配置，适配多行业、多核算模式。|

|角色|核心职责|权限范围约束|
|---|---|---|

|财务审核人员（终审）|逐笔审核结转草稿科目、金额、借贷、辅助核算准确性，标记审核状态，驳回异常草稿，确认待过账|不可生成草稿、不可修改模板、不可直接删除原始业务数据|
|财务主管/负责人|大额/异常结转专项审批、审批流配置、结转模板终审、月末关账确认、核查结转操作日志|可配置审批阈值，不可干预常规制单审核流程，禁止直接过账|

## 4\. 结转类型与标准模板定义

系统预置四大类标准结转模板，同时支持自定义结转，覆盖全行业常规期末核算场景，所有模板支持可视化配置、版本留存、权限管控。

### 4\.1 期间损益结转（标准必转）

自动归集当期所有收入类、成本费用类损益科目期末余额，全额结转至「本年利润」科目，结转后损益类科目余额归零，适配企业会计准则标准核算要求。支持按部门、项目等多辅助核算维度分项结转。

### 4\.2 成本结转（生产/商贸通用）

覆盖完整生产成本结转链路：制造费用结转→生产成本归集→完工产品入库结转→销售出库主营业务成本结转。支持加权平均、先进先出等主流存货计价方式，适配制造业、商贸业库存成本核算场景。

### 4\.3 税金结转（税务合规）

归集应交增值税各明细科目、附加税费、印花税等税费余额，完成期末税费结转至未交增值税、税金及附加对应科目，匹配税务申报口径，规避税会核算差异。

### 4\.4 自定义结转（全场景扩展）

支持用户自主配置取数来源、借贷科目、结转比例、辅助核算、触发条件，覆盖摊销、预提、折旧计提、往来对冲、专项费用结转等所有非标场景，适配建筑、地产、服务、外贸等行业特色业务。

## 5\. 标准操作流程（行业通用顺序，系统刚性控制）

系统强制固定结转执行顺序，前置校验不通过、前置流程未完成，禁止执行后续结转操作，杜绝账务逻辑错乱。

**标准执行顺序：期末检查 → 折旧/摊销计提 → 汇兑损益结转 → 制造费用结转 → 生产成本结转 → 库存成本结转 → 税金结转 → 损益结转 → 人工审核 → 确认过账**

### 5\.1 第一步：结转前置检查（人工发起，仅校验不操作）

财务人员进入期末结转模块，手动点击【开始期末检查】，系统全自动校验，校验不通过禁止进入结转流程。

系统完整校验项及提示规范：

|检查项|失败提示文案|处理逻辑|
|---|---|---|
|当期所有凭证全部过账|存在N张未审核未过账凭证，请先完成凭证审核过账。|阻断后续操作|
|当期银行流水全部对账完成|存在N笔银行流水未对账，请先完成银企对账。|阻断后续操作|
|结转模板配置完整有效|【XX结转】模板未配置/配置异常，请先维护模板。|阻断对应类型结转，其他正常模板可执行|
|存货单据全部核算完成|存在未核算库存单据，请先完成存货成本核算。|阻断成本类结转|
|固定资产折旧、无形资产摊销已计提|当期折旧/摊销未计提完成，请先执行计提操作。|阻断后续所有结转|
|往来科目无异常余额方向|存在往来科目余额方向异常，请人工核查。|预警提示，不阻断，留痕备查|

全部校验通过后，系统展示：**检查通过，可正常执行期末结转操作**。

### 5\.2 第二步：人工选择结转类型，生成草稿凭证

人工自主勾选需要执行的结转类型，点击【生成结转草稿】，系统仅生成草稿、不入账、不更新余额。

系统标准行为：

1. 读取当前会计期间、对应结转模板规则；

2. 读取当期合法科目期末余额，按规则计算分录、金额、借贷方向、辅助核算；

3. 批量生成结转凭证，状态固定为「草稿」，无任何账务数据变更；

4. 前端明确提示：**已生成X张结转凭证草稿，未入账，请逐张审核确认后再过账。**

5. 全程记录操作日志：操作人、时间、IP、设备、生成类型、凭证数量。

### 5\.3 第三步：人工逐张审核草稿凭证（核心人控节点）

审核人员进入草稿列表，必须**逐张点开详情审核**，禁止批量一键审核，保障账务精准性。

强制审核核查内容：

- 科目选用是否准确、匹配当期核算规则；

- 结转金额与科目余额表数据是否一致；

- 借贷方向、辅助核算维度是否正确；

- 是否存在多余结转、漏结转、错结转场景；

- 零余额跳过、异常分录是否合理合规。

审核可执行操作：

|操作|权限与规则说明|
|---|---|
|查看详情|查看完整分录、取数来源、科目余额、模板版本、操作日志|
|人工修改草稿|仅可修改草稿状态凭证，修改内容全程留痕，记录修改前后对比、操作人、时间，用于问题追溯与AI优化模板|
|删除草稿|错误草稿可删除，删除后可调整模板重新生成，删除行为全程日志留存|
|审核通过|标记为「已审核待过账」，进入待过账列表，审核后草稿禁止再次修改|
|审核驳回|填写驳回原因，退回草稿状态，由制单人员修正后重新提交|

### 5\.4 第四步：人工确认过账（最终闭环节点）

仅财务审核/主管人员可操作，人工勾选已审核无误的结转凭证，手动点击【确认过账】，系统执行原子事务入账。

系统过账前置二次校验：

- 校验凭证借贷平衡；

- 校验草稿自审核后无任何数据变更；

- 校验当前会计期间未关账，允许账务入账；

- 校验无并发修改冲突。

过账成功后系统行为：

1. 凭证状态由「草稿/已审核」变更为「已过账（正式凭证）」；

2. 正式更新对应科目期末余额、辅助核算余额；

3. 凭证纳入报表取数、账务统计、期末关账校验；

4. 锁定凭证数据，禁止直接修改、删除，调整仅支持红字冲销；

5. 更新结转任务状态为「已完成」，全流程日志固化留存。

关键界面强制提示：**过账后科目余额将正式更新，账务记录不可逆、不可撤销，请确认所有分录、金额无误后执行。**

## 6\. 完整状态流转（系统刚性锁定）

\[未执行\] → 人工点击生成草稿 → \[草稿已生成\] → 人工审核/修改/驳回 → \[已审核待过账\] → 人工确认过账 → \[已过账（正式入账）\]

- 禁止系统定时任务自动生成结转草稿；

- 禁止月末自动触发结转流程；

- 禁止审核通过后自动过账；

- 禁止任何跳过人工审核、人工过账的捷径机制；

- 禁止后台静默修改结转草稿与正式凭证数据。

## 7\. 异常处理机制（分级处理、可恢复、可追溯）

|异常场景|系统处理逻辑|人工处置方式|
|---|---|---|
|生成草稿时科目余额为零|自动跳过该分录，标注「余额为零，已跳过」，不生成无效分录，前台汇总提示|人工核对科目余额、当期业务是否正常|

## 8\. 权限与内控安全设计（审计合规级）

### 8\.1 权限互斥机制（强制）

系统底层固化权限互斥规则，无法人为修改：制单、审核、过账、模板配置四类权限两两互斥，杜绝一人包办全流程。

### 8\.2 数据不可篡改机制

- 草稿阶段：可修改删除，全程留存修改前后对比日志；

- 审核通过后：禁止修改、删除；

- 过账正式后：永久锁定，仅红字冲销可调账，冲销记录同样全程留痕。

### 8\.3 全流程操作留痕

所有结转相关操作全部记录不可删除日志，包含：操作人、账号、IP、设备指纹、操作时间、操作类型、变更内容、审核意见、驳回原因，日志留存时长不低于30年，满足审计、税务、内控检查要求。

### 8\.4 多级审批可配置

支持按结转金额、结转类型、业务维度配置分级审批流，普通财务审核后，大额/异常单据自动流转至财务主管终审。
