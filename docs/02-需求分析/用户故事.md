# 用户故事文档

## 概述

本文档记录了慧话财务管理系统的核心用户故事，用于指导开发和验收测试。每个用户故事遵循标准格式：

> **As a \[角色], I want to \[操作] so that \[收益]**

## 模块一：凭证管理

### US001 创建凭证

**作为** 会计人员\
**我希望** 创建记账凭证\
**以便** 记录企业的经济业务

**验收标准：**

- 系统自动生成凭证编号
- 支持选择凭证日期
- 至少需要录入一条分录
- 第一条分录必须填写摘要
- 系统自动校验借贷平衡
- 支持添加附件

### US002 编辑凭证

**作为** 会计人员\
**我希望** 编辑已创建的凭证\
**以便** 修改错误或补充信息

**验收标准：**

- 只能编辑状态为"草稿"的凭证
- 修改后重新校验借贷平衡
- 自动记录修改日志

### US003 删除凭证

**作为** 会计人员\
**我希望** 删除凭证\
**以便** 清除错误或不需要的记录

**验收标准：**

- 只能删除本人创建且状态为"草稿"的凭证
- 系统管理员可以删除任意凭证
- 删除后记录操作日志

### US004 提交凭证

**作为** 会计人员\
**我希望** 提交凭证进行审核\
**以便** 进入审批流程

**验收标准：**

- 只能提交状态为"草稿"的凭证
- 提交后状态变为"待审核"
- 自动通知审核人员

### US005 审核凭证

**作为** 财务主管\
**我希望** 审核凭证\
**以便** 确保凭证的准确性和合规性

**验收标准：**

- 可以查看凭证详情和分录
- 支持通过或拒绝审核
- 拒绝时需要填写拒绝理由
- 审核通过后状态变为"已审核"

### US006 记账凭证

**作为** 财务主管\
**我希望** 对已审核的凭证进行记账\
**以便** 更新总账数据

**验收标准：**

- 只能对已审核的凭证进行记账
- 记账后状态变为"已记账"
- 更新相关科目的余额

### US007 查询凭证

**作为** 会计人员\
**我希望** 查询凭证列表\
**以便** 查看和管理凭证

**验收标准：**

- 支持按凭证编号、日期范围、状态筛选
- 支持分页显示
- 显示制单人、状态、金额等关键信息

## 模块七：出纳日记账管理

### US020 录入日记账流水

**作为** 出纳\
**我希望** 逐笔录入现金和银行存款的收支流水，系统自动计算并展示实时余额\
**以便** 实现日清月结，确保账实相符

**验收标准：**

- 支持选择账户（现金/银行/支付宝/微信）
- 录入收支金额、日期、摘要、对方单位
- 系统自动计算并展示实时余额
- 支持编辑和删除未对账的流水记录
- 支持上传影像附件（发票、回单等）

### US021 多账户统一管理

**作为** 出纳\
**我希望** 同时管理多个银行账户和现金账户，一目了然查看所有资金动态\
**以便** 快速了解公司整体资金状况

**验收标准：**

- 账户列表展示，显示每个账户的当前余额
- 支持按账户类型筛选（现金/银行/第三方支付）
- 支持添加、编辑、停用账户
- 点击账户可查看该账户的流水明细

### US022 批量导入流水

**作为** 出纳\
**我希望** 批量导入Excel格式的流水文件\
**以便** 减少手工录入工作量

**验收标准：**

- 支持Excel/CSV格式导入
- 导入前显示预览和校验结果
- 支持字段映射（日期、金额、摘要等）
- 导入完成后显示成功/失败统计
- 失败行提供错误原因

### US023 业务单据自动生成日记账

**作为** 出纳\
**我希望** 通过已审核的业务单据（报销单、收款单、付款单）自动生成日记账\
**以便** 避免重复录入

**验收标准：**

- 系统自动将已审核的收付款单转为日记账记录
- 生成前可预览和编辑
- 同一单据不会重复生成
- 日记账记录关联原始业务单据

## 模块八：出纳银行对账

### US024 银行对账单导入

**作为** 出纳\
**我希望** 导入各大银行的电子对账单（CSV/Excel格式）\
**以便** 与系统日记账进行对账

**验收标准：**

- 支持主流银行对账单格式解析
- 支持手动上传文件
- 解析结果预览，确认无误后保存
- 支持同一账户多次导入对账单

### US025 自动勾稽对账

**作为** 出纳\
**我希望** 系统自动将日记账与银行对账单进行匹配（根据金额、日期、结算号）\
**以便** 快速找出未达账项

**验收标准：**

- 根据金额+日期+结算号自动匹配
- 匹配成功的记录自动标记为"已对账"
- 未匹配的记录标记为"未达账项"
- 支持手动调整匹配结果
- 显示对账进度和匹配率

### US026 生成银行存款余额调节表

**作为** 出纳\
**我希望** 一键自动生成标准的《银行存款余额调节表》\
**以便** 清晰展示账面余额与银行实际余额的差异原因

**验收标准：**

- 一键生成调节表
- 展示企业账面余额、银行对账单余额
- 列出所有未达账项（企业已收银行未收、银行已收企业未收等）
- 调节后余额相等
- 支持导出PDF格式

## 模块十一：智能回款核销流程

### US033 银行流水的导入与初筛

**作为** 一名出纳\
**我希望** 能批量导入银行的交易明细Excel文件，并对进账进行初步分类（区分业务回款与非业务款项）\
**以便** 我能快速将属于客户打款的记录推送到待处理池，同时过滤掉利息、内部转账等干扰项，确保后续核销数据的纯净

**验收标准：**

- 系统支持上传指定格式的Excel银行流水文件，并能正确解析日期、金额、对方户名和摘要字段
- 导入后，列表展示所有进账记录，每行提供"确认为业务回款"和"标记为非业务款项"的操作按钮
- 点击"确认为业务回款"后，该条记录状态变为"待认领"，并自动同步至应收会计的【待认领资金池】
- 一旦流水被推送至待认领池，出纳无法再修改该条记录的金额和付款方信息（保证数据不可篡改）

### US034 不明款项的销售协同认领

**作为** 一名销售人员\
**我希望** 能在系统中看到自己名下客户的未认领打款记录，并提交"这笔钱对应哪个合同"的建议\
**以便** 帮助财务同事快速理清那些备注不清的汇款归属，缩短对账周期

**验收标准：**

- 销售人员登录后，可在"我的回款"页面查看到包含其负责客户名称的"待认领"流水
- 针对某笔流水，销售可以点击"发起认领"，在弹窗中选择关联的客户及具体的销售订单/发票号，并填写备注说明
- 提交后，该流水的状态更新为"销售已建议"，并在会计的核销界面高亮显示销售的推荐结果供参考

### US035 多场景下的回款核销执行

**作为** 一名应收会计\
**我希望** 在一个界面上同时查看银行流水和未结清的发票，支持智能匹配、手动勾选以及金额拆分\
**以便** 我能高效、准确地完成一笔流水对应多张发票（或一张发票分多次收款）的复杂核销工作

**验收标准：**

- **界面布局**：采用左右分栏设计，左侧展示"待认领资金池"中的流水，右侧展示根据客户筛选出的"未结清发票"
- **智能提示**：当点击左侧某笔流水时，若系统根据金额或备注找到了高度匹配的发票，右侧自动勾选该发票并提示"系统推荐"
- **一对多/多对一操作**：允许我勾选左侧的一笔大额流水，同时在右侧勾选多张小额发票进行合并核销；反之亦然
- **尾差处理**：如果流水金额与勾选的发票总额不完全一致（存在微小差额），系统弹出"尾差处理"框，允许我将差额计入"财务费用-手续费"或"现金折扣"，核销后方可保存
- **结果反馈**：点击"确认核销"后，相关发票状态自动变更为"已收款"，并自动生成对应的收款记账凭证传递至总账

### US036 核销操作的审计与追溯

**作为** 一名财务经理\
**我希望** 系统能完整记录每一笔回款核销的操作日志，包括是谁在什么时间、将哪笔流水与哪张发票进行了关联\
**以便** 在出现账务争议或外部审计时，能够快速追溯资金流向和业务依据

**验收标准：**

- 在任意一张已收款的销售发票详情页中，可以查看到"收款记录"，并点击穿透查看到原始的银行流水信息（包含付款方、打款日期）
- 系统后台需记录核销操作的完整日志：`[202X-XX-XX 14:30] 用户[张三] 执行了核销操作：将流水[ID:10086] 与 发票[ID:INV-2023001] 进行关联，核销金额：5000元`
- 如果执行了"取消核销（反冲）"操作，系统必须保留原核销记录的痕迹，并生成一条新的反冲日志
