# 银行流水驱动业财一体化系统——需求分析书

版本：V2.0
日期：2026-05-26

---

## 一、项目背景与目标

### 1.1 背景

传统财务工作中，出纳需手动从网银下载流水，人工筛选分类后，分别录入收款单、付款单、费用单，再手工核销发票、制作凭证。工作重复、效率低，且易出错。

### 1.2 目标

建设一套以银行流水为驱动源、覆盖全资金形态的业财一体化系统。实现从资金数据获取、智能分类、业务核销，到财务凭证的全链路自动化。让财务团队核心职能从"录入"升级为"审核与例外管理"。

---

## 二、总体业务流程

系统围绕两条并行主线运行，汇合于总账凭证。

**第一条线：银行存款线（自动化主线）**

```
导入银行流水 → 智能分类 → 生成业务单据 → 人工核对与补全
    → 业务核销 → 登记银行日记账 → 银企对账 → 生成凭证 → 凭证审核
```

**第二条线：库存现金线（人工录入主线）**

```
发生现金业务 → 录入现金单据 → 单据审核 → 登记现金日记账
    → 现金盘点 → 生成凭证 → 凭证审核
```

---

## 三、用户角色与核心职责

| 角色 | 核心职责 |
|---|---|
| 出纳 | 导入银行流水；首次核对系统智能分类结果；处理"待处理流水池"；核对并确认非业务类单据（费用单、利息单、转账单）；登记现金日记账并执行现金盘点。不负责最终审核凭证。 |
| 应收/应付会计 | 管理发票；处理收款单/付款单与发票的核销；跟进应收/应付账款。 |
| 总账会计 | 配置凭证模板；审核生成的会计凭证并过账；处理月末结转。 |
| 财务主管 | 审核现金单据；审批特殊业务；监督整体流程。 |

## 四、功能性需求

### 模块一：基础数据与规则引擎

- **银行账户管理**：维护企业所有银行账户信息，区分"银行存款"与"库存现金"类型。
- **银行流水模板**：支持为各银行定义对账单格式，配置字段映射。
- **智能分类规则库**：维护流水关键字、金额方向、对方信息与业务类型的映射关系。
- **科目映射规则**：为银行费用单、利息收入单的费用/收入类别预置会计科目；为银行存款和库存现金账户绑定会计科目。

### 模块二：银行流水导入与智能分类

- **流水导入**：支持Excel、CSV、XML格式，自动解析并校验数据完整性。
- **重复校验**：自动拦截已导入的重复流水，防止数据错误。
- **智能分类引擎**：按规则将流水自动分为六类：
  1. 收款单（客户回款）
  2. 付款单（支付供应商）
  3. 银行费用单（手续费等）
  4. 利息收入单
  5. 银行转账单（内部账户调拨）
  6. 待处理类
- **待处理流水池**：集中管理无法自动分类的流水，出纳手动指定业务类型后生成对应单据。

### 模块三：业务单据管理

系统从银行流水生成六种标准单据：

| 单据类型 | 业务场景 | 核心功能 | 是否核销发票 |
|---|---|---|---|
| 收款单 | 客户回款 | 匹配销售发票，冲减应收账款 | 是 |
| 付款单 | 支付供应商货款 | 匹配采购发票，冲减应付账款 | 是 |
| 银行费用单 | 手续费、账户管理费等 | 出纳确认，直接确认为财务费用 | 否 |
| 利息收入单 | 存款利息 | 出纳确认，直接确认为利息收入 | 否 |
| 银行转账单 | 内部账户间资金调拨 | 确认转出/入账户，不产生损益 | 否 |
| 现金收/付款单 | 库存现金业务 | 人工录入，审核后登记现金日记账 | 可选 |

**单据通用规则：**
- 所有单据均需经过确认或审核后方可生效。
- 所有银行类单据确认后，自动登记银行日记账。
- 所有现金类单据审核后，自动登记现金日记账。

### 模块四：发票核销管理

- **自动核销引擎**：收款单/付款单确认后，按金额、客户/供应商自动匹配未核销发票。支持精确匹配、部分核销、多对多核销。
- **容差处理**：支持设置小额尾差自动核销阈值。
- **手工核销中心**：为复杂场景提供集中手工核销界面，支持手工勾单、输入本次核销金额。
- **状态联动**：核销完成时，实时更新发票状态，扣减应收应付账款余额。

### 模块五：银企对账

- **自动对账**：以金额、日期为条件，自动将银行日记账记录与导入的银行流水勾兑。
- **余额调节表**：自动归集未达账项，生成标准余额调节表，区分"企业已收付银行未收付"与"银行已收付企业未收付"。
- **手工对账**：支持特殊未达账项的强制勾兑。

### 模块六：现金管理

- **现金日记账**：实时反映库存现金的收支与结存，按会计期间查询。
- **现金盘点**：录入实盘库存现金，系统自动与现金日记账余额比对，生成盘点差异报告。

### 模块七：凭证生成与总账接口

- **凭证模板配置**：为六种单据预置凭证模板，定义借贷方科目、辅助核算取值规则。
- **一键/批量生成凭证**：已确认单据支持逐单或批量生成凭证。
- **凭证推送**：生成的凭证自动提交至总账模块待审核列表。
- **双向联查**：支持从总账凭证联查至源头银行流水，以及从银行流水追踪至最终凭证。
- **冲销机制**：已生成凭证的单据，如发现错误，必须通过红蓝字冲销，不可直接删除。

### 模块八：常用凭证模板

| 单据类型 | 借方 | 贷方 |
|---|---|---|
| 收款单 | 银行存款 | 应收账款 |
| 付款单 | 应付账款 | 银行存款 |
| 银行费用单 | 财务费用-手续费 | 银行存款 |
| 利息收入单 | 银行存款 | 财务费用-利息收入（红字） |
| 银行转账单 | 银行存款-转入账户 | 银行存款-转出账户 |
| 现金收款单 | 库存现金 | 应收账款 |
| 现金付款单 | 应付账款/费用类 | 库存现金 |

## 五、非功能性需求

- **高可靠性**：流水导入、单据生成、核销、登记日记账需保证数据库事务强一致性，杜绝数据错漏。
- **全链路可追溯**：从银行流水到总账凭证，任一环节可向前或向后追溯，满足审计要求。
- **操作防呆**：关键操作（如确认、生成凭证）需有二次确认或操作日志记录。
- **权限清晰**：出纳、会计、主管的操作权限严格分离，符合内控要求。
- **易用性**：手工核销中心、待处理流水池等人工交互界面，需提供清晰指引和批量处理能力。
