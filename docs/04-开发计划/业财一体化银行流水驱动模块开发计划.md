## 一、需求总结

### 1.1 核心业务流程
系统围绕两条并行主线运行，汇合于总账凭证：

**银行存款线（自动化主线）**：
```
银行流水导入 → 智能分类 → 生成业务单据 → 人工核对与补全
    → 业务核销 → 登记银行日记账 → 银企对账 → 生成凭证 → 凭证审核
```

**库存现金线（人工录入主线）**：
```
发生现金业务 → 录入现金单据 → 单据审核 → 登记现金日记账
    → 现金盘点 → 生成凭证 → 凭证审核
```

### 1.2 单据类型与处理策略

| 单据类型 | 分类标识 | 处理方式 | 是否核销发票 |
|---------|---------|---------|-------------|
| 收款单 | business_receipt | 出纳确认后生成凭证 | 是 |
| 付款单 | business_payment | 出纳确认后生成凭证 | 是 |
| 银行费用单 | bank_fee | 自动生成凭证 | 否 |
| 利息收入单 | interest_income | 自动生成凭证 | 否 |
| 银行转账单 | internal_transfer | 自动生成凭证 | 否 |
| 待处理类 | pending | 人工分类后处理 | - |

### 1.3 关键新增需求

**期初建账与余额管理**：
- 期初余额录入：系统启用时录入各银行账户期初余额
- 余额一致性检查：定期核对系统余额与银行余额
- 余额调节：支持手工调整期初余额（需审批）
- 账户启用/禁用管理

**银企对账增强**：
- 余额一致性校验：自动校验账实相符
- 对账差异报告：生成未达账项明细及差异原因

## 三、技术方案

### 3.1 核心数据模型

#### 银行账户模型增强

```go
type BankAccount struct {
    ID              uuid.UUID      // 账户ID
    TenantID        uuid.UUID      // 租户ID
    CompanyID       uuid.UUID      // 公司ID
    AccountName     string         // 账户名称
    BankName        string         // 开户行
    AccountNo       string         // 银行账号
    AccountType     string         // 账户类型：bank/cash
    OpeningDate     time.Time      // 启用日期
    OpeningBalance  decimal.Decimal // 期初余额
    CurrentBalance  decimal.Decimal // 当前余额（计算字段）
    IsEnabled       bool           // 是否启用
    CreatedAt       time.Time
    UpdatedAt       time.Time
}
```

#### 凭证模板模型

```go
type VoucherTemplate struct {
    ID              uuid.UUID      // 模板ID
    TenantID        uuid.UUID      // 租户ID
    Classification  string         // 分类标识（business_receipt等）
    Name            string         // 模板名称
    DebitAccountID  uuid.UUID      // 借方科目ID
    CreditAccountID uuid.UUID      // 贷方科目ID
    IsActive        bool           // 是否启用
    CreatedAt       time.Time
}
```

### 3.2 关键接口设计

#### 期初余额管理

| API | 方法 | 功能 |
|-----|------|------|
| `/api/v1/bank-accounts` | POST | 创建银行账户（含期初余额） |
| `/api/v1/bank-accounts/:id` | PUT | 更新银行账户 |
| `/api/v1/bank-accounts/:id/enable` | POST | 启用账户 |
| `/api/v1/bank-accounts/:id/disable` | POST | 禁用账户 |
| `/api/v1/bank-accounts/:id/adjust-balance` | POST | 调整期初余额 |

#### 凭证生成

| API | 方法 | 功能 |
|-----|------|------|
| `/api/v1/voucher-templates` | GET/POST | 凭证模板CRUD |
| `/api/v1/vouchers/generate/bank-txn/:id` | POST | 从流水生成凭证 |
| `/api/v1/vouchers/generate/batch` | POST | 批量生成凭证 |
| `/api/v1/vouchers/preview/bank-txn/:id` | GET | 预览凭证 |

#### 银企对账

| API | 方法 | 功能 |
|-----|------|------|
| `/api/v1/reconciliation/auto` | POST | 自动对账 |
| `/api/v1/reconciliation/manual` | POST | 手工对账 |
| `/api/v1/reconciliation/statement` | GET | 获取余额调节表 |
| `/api/v1/reconciliation/diff-report` | GET | 获取对账差异报告 |
| `/api/v1/reconciliation/balance-check` | GET | 余额一致性校验 |
