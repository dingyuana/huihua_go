## 四、验收标准

### 4.1 功能验收

| 验收点 | 验收方法 | 预期结果 |
|--------|---------|---------|
| 重复发票号合并 | 导入含 3 行同发票号的 Excel | 生成 1 条发票记录 + 3 条行项目 |
| 跨导入重复拦截 | 再次导入已存在的发票号 | 报错提示冲突，导入被拒绝 |
| 行项目数据 | 查看发票详情或展开行 | 显示货物名称、数量、单价 |
| 红字识别 | 导入"是否正数发票=否"的行 | 红字标签显示为"红字" |
| 蓝字关联 | 红字发票备注含"对应蓝字发票号" | 对应蓝字发票列显示提取结果 |
| 条件展开 | 查看 0/1/2+ 行项目的发票 | 仅 2+ 子项显示展开图标 |
| 序号 | 列表查看 | 每行有递增序号 |

### 4.2 异常验收

| 验收点 | 验收方法 | 预期结果 |
|--------|---------|---------|
| 空文件 | 上传空 Excel | 返回友好错误提示 |
| 全重复导入 | 导入全部已在系统中的发票号 | 返回冲突列表，全部拒绝 |
| 部分重复 | 部分发票号已在系统中 | 返回冲突明细，全部拒绝 |
| 非法文件 | 上传非 Excel 文件 | 返回文件格式错误 |
| 金额为负 | 导入含负金额 | 正常导入（红字允许负数） |

## 五、风险评估

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|---------|
| 现有 UNIQUE 约束依赖 | 解除后其他模块可能受影响 | 低 | 检查所有 `GetByInvoiceNo` 使用场景：均返回单条，去除 UNIQUE 后需加 `LIMIT 1` 或处理多条 |
| 大文件导入性能 | 5000 行分组处理耗时 | 中 | 分组用 map 聚合，事务批量写入 |
| 备注提取准确率 | 蓝字号提取失败 | 低 | 提供独立列 fallback，提取失败不阻塞 |
