# 慧财智能财务平台 - 前端项目

## 开发
```bash
pnpm install
pnpm dev
```

## 构建
```bash
pnpm build
```

## 目录说明
```
src/
├── api/          # API 请求层
├── components/   # 公共组件
├── config/       # 应用配置
├── directives/   # 自定义指令
├── hooks/        # 组合式函数
├── router/       # 路由
├── stores/       # 状态管理
├── styles/       # 样式
├── types/        # TypeScript 类型
├── utils/        # 工具函数
└── views/        # 页面
```
